Installation

To keep render times functionally instant, Dynamoblobs intentionally skips pulling in a library such as SVG.js to build a new shape on execution.

Instead, it builds a randomly seeded closed <path> from criteria you set, then leverages an HTML web component (sorry, IE) to read its own attributes and swap itself in for a slick lil' blob — one that wobbles, morphs, and can even drift around its container.

You can install Dynamoblobs via npm, a CDN, or by including the script file directly in your project.

npm Installation

To install Dynamoblobs via npm, run the following command:

npm install dynamoblobs

After installation, import Dynamoblobs once in your JavaScript or TypeScript entry file to register the element globally:

import 'dynamoblobs';

Angular Setup

To use Dynamoblobs in an Angular project, follow these additional steps after installing via npm:

  1. In your angular.json file, add the dynamoblobs script to the scripts array:
"scripts": [
    "node_modules/dynamoblobs/dist/dynamoblobs.js"
  ]
  1. In your app.module.ts file, add CUSTOM_ELEMENTS_SCHEMA to the schemas array:
import { NgModule, CUSTOM_ELEMENTS_SCHEMA } from '@angular/core';

  @NgModule({
  // ...
  schemas: [CUSTOM_ELEMENTS_SCHEMA]
  })

  export class AppModule { }

Script Installation

Alternatively, include the Dynamoblobs script file directly in your project:

<!-- Download and add to your project locally -->
<script src="path/to/dynamoblobs.js"></script>

<!-- Or, reference the CDN -->
<script src="https://cdn.jsdelivr.net/gh/mzebley/dynamoblobs/dist/dynamoblobs.min.js" crossorigin="anonymous"></script>

Usage

Since Dynamoblobs is an HTML custom element, all it takes to drop one in is to add the tag to your markup. Give it a size with CSS — the blob scales to fit its host.

<!-- A blob, filled with the current color of its parent -->
<dynamo-blob style="width:120px;height:120px"></dynamo-blob>

A dynamo-blob inherits any class, id, or style applied to its invoking element, and the path inherits your fill.

<!-- Example 1 -->
<dynamo-blob style="width:120px;height:120px;fill:slateblue"></dynamo-blob>

<style>
    .fill-theme { fill: var(--theme); }
</style>

<!-- Example 2 -->
<dynamo-blob class="fill-theme" style="width:120px;height:120px"></dynamo-blob>

Data Attributes

Dynamoblobs ship with a set of data attributes for tuning their shape and motion.

Points and Variance

A dynamo-blob generates a new, randomized silhouette each time it renders. The shape is built from points — the number of vertices around the ring — and variance, how far each vertex can deviate from the base radius.

AttributeDefaultOptions

data-blob-points

10Any integer ≥ 3

data-blob-variance

8Any positive number
 
<dynamo-blob data-blob-points="14" data-blob-variance="14"></dynamo-blob>

Deterministic blobs

Every generated blob encodes its exact SVG path into data-blob-seed. Copy that attribute to reproduce the same shape anywhere — the two blobs below share one seed:

<dynamo-blob data-blob-seed="ENCODED_PATH_OR_ANY_STRING"></dynamo-blob>

A seed can be the compact path string the component writes back to data-blob-seed (reproduces the exact path), or any arbitrary string (deterministically seeds generation).

Motion: wobble, morph & drift

Every blob has three independent motion layers, and they're always ready to go. You don't enable them — you decide whether each one auto-plays on render, and you can play or pause any of them live. The attributes follow one pattern across all three:

PatternPurpose

data-blob-<layer>-autoplay

Start this layer on render (true / false).

data-blob-is-<layer>ing

Set false to pause, true to play. Also reflects the live state.

data-blob-<layer>-speed

How fast the layer runs.

data-blob-<layer>-intensity

How strong the effect is.

Accessibility: the *-autoplay flags are suppressed when the viewer has reduced motion enabled. Explicit play (an is-* attribute or a JS call) is treated as intentional and runs regardless.

Wobble

By default a blob gently wobbles — a continuous CSS turn, skew, and scale. Set the speed and skew intensity, or pause it.

AttributeDefaultOptions

data-blob-wobble-autoplay

truetrue, false

data-blob-is-wobbling

reflects statetrue, false

data-blob-wobble-speed

30000Period in milliseconds

data-blob-wobble-intensity

2Skew intensity multiplier
 
<dynamo-blob data-blob-wobble-speed="12000" data-blob-wobble-intensity="3"></dynamo-blob>

The second blob sets data-blob-wobble-autoplay="false", so it sits still until you start it — via playWobble(ms) or by setting data-blob-is-wobbling="true".

Morph

Want a blob that endlessly reshapes itself? Turn on data-blob-morph-autoplay and the blob continuously regenerates and morphs between silhouettes. data-blob-morph-speed sets the per-cycle duration; data-blob-morph-intensity sets how far each cycle reshapes it.

AttributeDefaultOptions

data-blob-morph-autoplay

falsetrue, false

data-blob-is-morphing

reflects statetrue, false

data-blob-morph-speed

7500Per-cycle duration in milliseconds

data-blob-morph-intensity

1How dramatic each reshape is

data-blob-morph-tween

600Tween (ms) when a shape attribute changes live; 0 snaps

Consistent drama: morph-intensity holds the amount of change constant from one cycle to the next, so the loop never lands on a near-identical shape and stalls. Higher values stay reliably bold.

<dynamo-blob data-blob-morph-autoplay="true" data-blob-morph-speed="4000"></dynamo-blob>

The right-hand blob uses a higher data-blob-morph-intensity for bigger swings.

Drift

Set data-blob-drift-autoplay and the blob bounces around its nearest positioned, sized ancestor. Add data-blob-drift-click to send it off in a new direction on click, and data-blob-drift-intensity to tune how it reacts to the walls. Stack a few for an ambient background.

AttributeDefaultOptions

data-blob-drift-autoplay

falsetrue, false

data-blob-is-drifting

reflects statetrue, false

data-blob-drift-speed

1.25Any positive number

data-blob-drift-intensity

1Bounce restitution: 1 elastic, <1 damps, >1 energizes

data-blob-drift-click

falsetrue, false

data-blob-drift-start-position

randomrandom, center, current
 
<div style="position:relative;height:240px;overflow:clip">
  <dynamo-blob data-blob-drift-autoplay="true" data-blob-drift-click="true" style="width:70px;height:70px"></dynamo-blob>
</div>

Tip: click a blob above to deflect it.

Pause everything

data-blob-is-animating is the master switch. Set it to false to freeze all three layers in place; set it to true to resume the ones configured to auto-play. It also reflects the live state — true whenever any layer is playing — and is exposed as .isAnimating.

AttributeDefaultOptions

data-blob-is-animating

reflects statetrue, false
 
<dynamo-blob data-blob-is-animating="false"></dynamo-blob>

Observation

Leaning into generative design? data-blob-observe wires up an IntersectionObserver that regenerates the blob as it leaves the viewport.

AttributeDefaultOptions

data-blob-observe

unset
  • once Regenerate once when leaving the viewport
  • continuous Regenerate every time it leaves
  • once:300px Add a custom root margin
  • continuous:100px Combine mode with margin
 
<dynamo-blob data-blob-observe="continuous:100px"></dynamo-blob>

Available Functions

Dynamoblobs expose a small runtime API for controlling a blob after it has rendered.

.generateNewBlob()

Want a fresh shape? Call generateNewBlob(duration) on the blob you'd like to regenerate. The optional duration controls how quickly the old silhouette morphs into the new one — default is 800(ms).

const blob = document.querySelector('dynamo-blob');
blob.generateNewBlob(500);

.play()

play() resumes every layer the blob is configured to auto-play — wobble (on by default), the morph loop (when data-blob-morph-autoplay is set), and drift (when data-blob-drift-autoplay is set).

Pass an options object to force a layer on and tune its timing. Morph and wobble durations are in milliseconds; drift takes a speed multiplier.

const blob = document.querySelector('dynamo-blob');

blob.play();                                          // resume what's enabled
blob.play({ morph: 4000 });                           // force morphing on at 4s cycles
blob.play({ morph: 4000, wobble: 20000, drift: 2 });  // force + tune all three

.pause()

pause() freezes the wobble, the morph loop, and drift in place.

Granular controls

Prefer to drive one layer at a time? Each animation has its own play/pause pair. Durations are in milliseconds; drift takes a speed multiplier.

blob.playWobble(20000);  blob.pauseWobble();  // ambient CSS wobble
blob.playMorph(4000);    blob.pauseMorph();   // morph loop
blob.playDrift(2);       blob.pauseDrift();   // drift

// Each layer exposes its live state (also mirrored to data-blob-is-* attributes):
blob.isWobbling;  blob.isMorphing;  blob.isDrifting;
blob.isAnimating; // true when any layer is playing

// Toggle just the morph loop off its own state:
blob.isMorphing ? blob.pauseMorph() : blob.playMorph(5000);

Reduced motion: explicit play*() calls run regardless of prefers-reduced-motion — only the declarative *-autoplay attributes honor it.

.deflect()

For a drifting blob (see data-blob-drift-autoplay), deflect() kicks it off in a new random direction — the same thing a click does when data-blob-drift-click is set.

Need to know when a morph finishes? Listen for the dynamo-blob-complete event to react when a cycle ends.

document.querySelector('dynamo-blob')
  .addEventListener('dynamo-blob-complete', (event) => {
    console.log('Blob finished morphing', event.detail);
  });

Practical Application

Dynamoblobs are entirely style-agnostic out of the box. The onus is on you to size and color them for your platform — but that also means nearly endless room for customization.

Ambient layered background

A few drifting blobs at low opacity make a living, generative backdrop — the same trick behind a hero section. Stack them in a positioned, clipped container.

<div class="hero" style="position:relative;overflow:clip">
  <dynamo-blob data-blob-drift-autoplay="true" style="width:160px;height:160px;opacity:.5"></dynamo-blob>
  <dynamo-blob data-blob-drift-autoplay="true" style="width:110px;height:110px;opacity:.5"></dynamo-blob>
  <dynamo-blob data-blob-drift-autoplay="true" style="width:80px;height:80px;opacity:.5"></dynamo-blob>
  <h2>Generative by default</h2>
</div>

Generative by default

Organic avatar accent

Pair a static blob with content for a soft, hand-drawn frame that's never quite the same twice.

<div style="display:flex;align-items:center;gap:1rem">
  <dynamo-blob data-blob-morph-autoplay="true" data-blob-morph-speed="9000"
    style="width:96px;height:96px;fill:var(--theme)"></dynamo-blob>
  <div>
    <h3>Eye-catching headline.</h3>
    <p>Further information to draw interest.</p>
  </div>
</div>
